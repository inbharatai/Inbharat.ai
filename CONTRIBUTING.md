# Contributing to InBharat AI

Thank you for your interest in contributing.

## Development setup

1. Fork and clone the repo.
2. `npm install`
3. Copy `.env.example` to `.env` and add your keys (see [README](README.md#environment-variables)).
4. `npm run dev`

## Code quality

- Run `npm run lint` and fix any issues before submitting.
- Use TypeScript and existing patterns (e.g. `AgentMode`, `Message` from `types.ts`).

## Submitting changes

1. Create a branch from `main`.
2. Make your changes and ensure `npm run lint` passes.
3. Open a Pull Request with a clear description of the change.

## Questions

Open an [Issue](https://github.com/inbharatai/Inbharat.ai/issues) for bugs or feature ideas.
